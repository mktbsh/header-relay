# Chrome Web Store 리스팅 (한국어)

Developer Dashboard의 "스토어 등록정보" 한국어 로컬라이즈용 텍스트.

## Product Details

### Name

Header Relay — HTTP 요청 헤더 수정 및 응답 헤더 캡처

### Summary

HTTP 응답 헤더를 캡처하고 고정 또는 캡처한 요청 헤더를 API 개발 및 테스트용으로 중계합니다.

### Category

Developer Tools

### Language

Korean

### Detailed Description

Header Relay는 API 또는 웹 앱이 커스텀 헤더, 게이트웨이 헤더, 세션 토큰, 트레이스 ID, 환경별 요청 메타데이터에 의존하는 경우 브라우저 기반 HTTP 요청 동작을 검증할 수 있는 개발자용 확장 프로그램입니다.

프로필을 만들고 대상 오리진을 선택하고 고정 요청 헤더를 설정한 뒤 캡처할 응답 헤더를 지정합니다. 대상 응답에 설정된 헤더가 포함되어 있으면 Header Relay는 해당 값을 현재 브라우저 세션 동안 메모리에만 유지하고 Chrome declarativeNetRequest 세션 규칙을 사용하여 이후 일치하는 요청에 부여합니다.

주요 기능:

- 로컬, 스테이징, 사내, 테스트 환경을 위한 오리진 단위 헤더 중계.
- 항상 요청에 부여되는 고정 헤더.
- 세션 토큰, 트레이스 ID 등을 자동 캡처하는 캡처 헤더.
- 에셋 또는 특정 엔드포인트를 헤더 부여 대상에서 제외하는 제외 경로 glob 패턴.
- 저장 전에 glob 매칭 규칙을 확인할 수 있는 제외 경로 테스터.
- URL이 대상인지 제외인지, 어떤 헤더가 부여되는지 미리 확인하는 URL Probe(저장 전 Draft에서도 동작).
- 프로필, 오리진, 헤더, 제외 경로, URL Probe, 감사 로그를 섹션별로 전환하는 전체 페이지 설정 화면.
- 여러 프로필 동시 활성화 및 더 이상 필요하지 않은 프로필 삭제.
- Popup과 설정 화면에서 공유하는 기본 및 컴팩트 표시 모드.
- Popup과 설정 화면에서 통일된 iOS 스타일 UI.
- 활성 헤더, 캡처된 값, 세션 상태, DNR 규칙 수를 간결하게 보여주는 Popup.
- 자동 보존을 지원하는 로컬 감사 로그(요청 URL은 영구 저장하지 않음).
- 일본어, 한국어, 스페인어, 프랑스어, 독일어, 중국어 간체, 중국어 번체 로컬라이즈 지원.

개인정보 보호 및 보안:

- Header Relay는 프로필 설정, 감사 로그, 사용 이벤트, 분석 식별자, 브라우징 데이터 또는 캡처한 헤더를 개발자, 분석 제공업체 또는 관련 없는 서버로 전송하지 않습니다. 설정한 헤더 값은 일치하는 대상 오리진에 대한 요청에만 추가됩니다.
- 캡처된 값은 메모리의 세션 스토리지에만 유지되며 브라우저 재시작, 확장 프로그램 비활성화, 다시 로드, 업데이트, 프로필 비활성화, 규칙 변경, 호스트 권한 취소 또는 수동 지우기 시 삭제됩니다. UI에서는 개발자가 확인할 수 있도록 값을 그대로 표시합니다.
- 민감한 헤더 이름에는 경고를 표시합니다. `Cookie`는 브라우저 상태와의 충돌을 경고한 뒤 개발 워크플로에서 사용할 수 있으며, 응답 전용 및 전송 제어 헤더는 거부됩니다.
- 감사 로그에 요청 URL은 저장되지 않습니다. URL은 오리진 일치 판정을 위해 메모리에서만 처리되며 브라우저 종료 시 삭제됩니다.
- 기본 로컬 개발 워크플로를 위해 HTTP localhost 액세스가 포함됩니다. 그 외 호스트는 대상 오리진을 추가할 때만 요청하며 optional 권한은 Chrome 확장 프로그램 설정에서 언제든지 해제할 수 있습니다.

이 확장 프로그램은 개발자 및 QA 워크플로우를 위한 것입니다. 로컬 브라우저 프로필에서 허용되는 경우를 제외하고 프로덕션 자격 증명 저장에는 사용하지 마세요.

Version 0.5.0 — 오리진별 호스트 권한, 캡처 값의 세션 전용 보관, 민감한 헤더 보호, 프로필 삭제, 컴팩트 표시 및 진단 전용 감사 로그를 추가했습니다.

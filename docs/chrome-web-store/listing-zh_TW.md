## Product Details

### Name

Header Relay — 修改 HTTP 請求標頭並擷取回應標頭

### Summary

擷取 HTTP 回應標頭，並中繼固定或已擷取的請求標頭，用於 API 開發與測試。

### Category

Developer Tools

### Language

Chinese (Traditional)

### Detailed Description

當 API 或 Web 應用程式依賴自訂標頭、閘道標頭、工作階段權杖、追蹤 ID 或特定環境的請求中繼資料時，Header Relay 可協助開發者驗證瀏覽器端的 HTTP 請求行為。

建立設定檔、選擇目標來源、設定固定請求標頭，並列出要擷取的回應標頭。當相符的回應包含已設定的擷取標頭時，Header Relay 會在目前瀏覽器工作階段期間將該值保存在記憶體中，並使用 Chrome 的 declarativeNetRequest 工作階段規則，將其附加到之後相符的請求上。

主要功能：

- 針對本機、預備、內部與測試環境的按來源標頭中繼。
- 用於一律附加之數值的固定請求標頭。
- 用於工作階段權杖、追蹤 ID 或閘道標頭等數值的擷取回應標頭。
- 用於資源或不應接收中繼管理標頭之端點的排除路徑 glob 模式。
- 排除路徑測試工具，可在儲存前檢查 glob 比對規則。
- URL Probe 可檢查某個 URL 是否相符、是否遭排除，以及將附加哪些標頭——對尚未儲存的草稿同樣有效。
- 全頁設定介面，依設定檔、來源、標頭、排除路徑、URL Probe 及稽核記錄分區瀏覽。
- 可同時啟用多個設定檔，不再需要的設定檔可個別刪除。
- 彈出視窗與設定頁面共用的舒適與精簡兩種顯示模式。
- 彈出視窗與設定頁面統一的 iOS 風格介面，帶來一致的原生體驗。
- 精簡的彈出視窗狀態檢視，顯示使用中標頭、已擷取數值、工作階段狀態與 DNR 規則數量。
- 具備自動保留原則的本機稽核記錄；請求 URL 永不永久儲存。
- 支援日文、韓文、西班牙文、法文、德文、簡體中文及繁體中文本地化。

隱私與安全性：

- Header Relay 不會將設定檔設定、稽核記錄、使用事件、分析識別碼、瀏覽資料或已擷取的標頭傳送給開發者、分析服務供應商或無關的伺服器。已設定的標頭值僅會附加到與目標來源相符的請求上。
- 擷取的數值僅保存在記憶體中的工作階段儲存空間內，於瀏覽器重新啟動、擴充功能停用/重新載入/更新、設定檔停用、規則變更、主機存取權撤銷或手動清除時會被清除；介面中會原樣顯示，方便開發者檢視。
- 敏感標頭名稱會顯示警告。`Cookie` 在明確提示瀏覽器狀態風險的前提下仍可用於開發流程；僅限回應使用或由傳輸層管理的標頭會遭拒絕。
- 稽核記錄不會保存請求 URL：URL 僅在記憶體中用於來源比對處理，瀏覽器關閉時即會捨棄。
- 預設包含用於本機開發工作流程的 HTTP localhost 存取權。其他任何主機僅在新增對應目標來源時才會要求存取，且可隨時透過 Chrome 擴充功能設定撤銷選用權限。

此擴充功能適用於開發者與 QA 工作流程。除非在您的本機瀏覽器設定檔中可接受，否則請勿使用它保存正式環境憑證。

版本 0.5.0——新增按來源劃分的主機權限、僅限工作階段的擷取數值、敏感標頭保護、可刪除的設定檔、精簡顯示設定，以及僅供診斷用途的稽核記錄。

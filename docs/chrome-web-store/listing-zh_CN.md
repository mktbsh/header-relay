## Product Details

### Name

Header Relay — 修改 HTTP 请求标头并捕获响应标头

### Summary

捕获 HTTP 响应标头，并中继固定或已捕获的请求标头，用于 API 开发和测试。

### Category

Developer Tools

### Language

Chinese (Simplified)

### Detailed Description

当 API 或 Web 应用依赖自定义标头、网关标头、会话令牌、跟踪 ID 或特定环境的请求元数据时，Header Relay 可帮助开发者验证基于浏览器的 HTTP 请求行为。

创建配置文件，选择目标源，配置固定请求标头，并列出需要捕获的响应标头。当匹配的响应包含已配置的捕获标头时，Header Relay 会在当前浏览器会话期间将该值保存在内存中，并使用 Chrome 的 declarativeNetRequest 会话规则将其附加到后续匹配的请求上。

主要功能：

- 针对本地、预发布、内部和测试环境的按源标头中继。
- 用于始终附加的值的固定请求标头。
- 用于会话令牌、跟踪 ID 或网关标头等值的捕获响应标头。
- 用于资源或不应接收中继管理标头的端点的排除路径 glob 模式。
- 排除路径测试器，可在保存前检查 glob 匹配规则。
- URL Probe 可检查某个 URL 是否匹配、是否被排除，以及将附加哪些标头——对未保存的草稿同样有效。
- 全页设置界面，按配置文件、源、标头、排除路径、URL Probe 和审计日志分区导航。
- 可同时启用多个配置文件，不再需要的配置文件可单独删除。
- 弹出窗口和设置页面共享的舒适与紧凑两种显示模式。
- 弹出窗口与设置页面统一的 iOS 风格界面，带来一致的原生体验。
- 紧凑的弹出窗口状态视图，显示活动标头、已捕获的值、会话状态和 DNR 规则数量。
- 具有自动保留策略的本地审计日志；请求 URL 永不持久化保存。
- 支持日语、韩语、西班牙语、法语、德语、简体中文和繁体中文本地化。

隐私与安全：

- Header Relay 不会将配置文件设置、审计日志、使用事件、分析标识符、浏览数据或已捕获的标头发送给开发者、分析服务商或无关服务器。已配置的标头值仅会附加到与目标源匹配的请求上。
- 捕获的值仅保存在内存中的会话存储内，浏览器重启、扩展程序禁用/重新加载/更新、配置文件禁用、规则变更、主机访问权限撤销或手动清除时会被清除；界面中会原样显示，便于开发者查看。
- 敏感标头名称会显示警告。`Cookie` 在明确提示浏览器状态风险的前提下仍可用于开发流程；仅限响应使用或由传输层管理的标头会被拒绝。
- 审计日志不会保存请求 URL：URL 仅在内存中用于源匹配处理，浏览器关闭时即被丢弃。
- 默认包含用于本地开发工作流的 HTTP localhost 访问权限。其他任何主机仅在添加对应目标源时才会请求访问，且可随时通过 Chrome 扩展程序设置撤销可选权限。

此扩展程序适用于开发者和 QA 工作流程。除非在您的本地浏览器配置文件中可以接受，否则请勿使用它保存生产环境凭据。

版本 0.5.0——新增按源划分的主机权限、仅限会话的捕获值、敏感标头保护、可删除的配置文件、紧凑显示设置，以及仅用于诊断的审计日志。
